# exam-countdown

中考 / 高考桌面悬浮倒计时（Python + tkinter，纯标准库，无需安装任何依赖）。

无边框、置顶、透明背景的圆角卡片悬浮窗，实时显示距离开考的 **天 / 时 / 分 / 秒**，带秒针脉冲与淡入动画。

## 运行环境

- Python 3（自带 tkinter，Windows 一般已内置）
- 无第三方依赖，直接运行：

```bash
python countdown.py
```

## 操作方式

| 操作 | 效果 |
|---|---|
| 鼠标左键按住拖动 | 移动悬浮窗位置 |
| 点击顶部「中考 / 高考」胶囊 | 切换考试类型 |
| 按 `Tab` 键 | 在中考 / 高考之间快速切换 |
| 右键单击窗口 / 按 `F2` | 打开「设置考试时间」弹窗 |
| 右键单击 →「尺寸」 | 切换 小 / 中 / 大 三档大小 |
| 按 `Esc` 键 | 退出程序 |

## 调整尺寸

右键单击窗口 →「尺寸」，可选 **小 / 中 / 大** 三档，卡片与字号整体缩放，选择后自动存入 `config.json`，下次启动保持。

## 修改考试时间

无需改代码：在窗口上**右键单击**选「设置考试时间」，或按 `F2`，在弹窗里分别填写中考、高考的开考时间（格式 `年-月-日 时:分`，例如 `2027-06-20 09:00`），点保存即可。

保存后时间写入 EXE（或脚本）同目录的 `config.json`，下次启动自动读取；删除该文件即恢复默认时间。

## 源码可调项

打开 `countdown.py` 顶部可调整默认值与外观：

- `DEFAULT_ZK` / `DEFAULT_GK`：首次运行的中考、高考默认开考时间
- `DEFAULT_EXAM`：启动默认显示 `"zk"` 中考 / `"gk"` 高考
- `INIT_X, INIT_Y`：窗口初始位置
- `COLOR_*` / `ACCENT`：卡片配色与两种考试的强调色

## 说明

- 中考为青蓝强调色，高考为金橙强调色。
- 到达或超过开考时间后，数字归零并显示「已开始 · 加油！」。
- 跨平台：Windows 使用透明色，Linux 自动降级为半透明。
